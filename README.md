## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/techwithmranand-portfolio.git
```

### Navigate to the project

```bash
cd techwithmranand-portfolio
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```

## 📦 Build for Production

```bash
npm run build
```

## 📸 Preview Production Build

```bash
npm run preview
```
